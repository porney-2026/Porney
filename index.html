A quick note

How PORNEY works

Designed to help users navigate a directory without copying or hosting media files.

External links only

Listing cards open the destination site. PORNEY does not download, mirror, or stream media. Source titles and page contents can change at any time.

Thumbnails are optional

Video sites generally do not let a static page safely read their Open Graph metadata across domains. This version uses designed poster placeholders. Add a direct image URL in the listing data only when you have permission to use it.

Keep the catalogue accurate

Use factual titles and tags. Verify adult status, consent, content rights, and link availability before adding or promoting a listing. Do not list material involving minors or non-consensual intimate imagery.

SEO needs a real host URL

Before launch, set the canonical URL and social preview URL for the approved hosting domain. A single-page link directory may have limited search visibility without original, useful, crawlable content.
